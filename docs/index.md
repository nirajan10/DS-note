## About the Course

This course introduces the basic ideas of **data science**: using data to find answers and make better decisions. You will learn it with **Python**, a programming language that reads almost like English. You will write code to store data, clean it, explore it, draw charts, and teach a computer to make simple predictions.

No earlier knowledge of programming, Python or AI is needed. Every new word is explained the first time it appears. Most lessons use everyday data: student marks, shop sales, mobile data use and cricket scores.

## What You Will Learn

- The basic ideas of data science, and how to write Python programs with simple syntax, control structures, functions and modules.
- How to store and handle data with lists, tuples, sets and dictionaries.
- How to explore a dataset with statistics, charts and correlation.
- How to build and check simple machine learning models in Python.
- How to turn results into charts and dashboards that others can understand.
- How to use all of this on real datasets in practical lab projects.

## How to Use These Notes

- **Read in order.** Each unit builds on the one before it.
- **Every unit page has the same shape:** learning objectives, topics, a quick recap, exercises, and a link to exam questions.
- **Run the code yourself.** Every code block works as written. The result you should see is shown right under it. Set up Python first on the [setup page](setup.md).
- **Look for the boxes.** "Common Mistake" shows where beginners slip. "Ask the Class" is a question to answer before reading on.
- **Try the exercises before opening the answer.** The answers are hidden on purpose.
- **Practice at the computer.** Use the [lab sheets](practicals.md). The data files used in the notes are listed on the [setup page](setup.md#practice-data-files).

## The Eleven Units

<div class="grid cards" markdown>

- **[Unit I: Introduction to Data Science and Python](unit-01-intro.md)**

    ---

    3 hours. What data science is, where it is used, how a project flows, and how to start with Python.

- **[Unit II: Python Programming Basics and Operators](unit-02-basics.md)**

    ---

    3 hours. Variables, data types, operators, converting types, and your first Python program.

- **[Unit III: Control Structures](unit-03-control.md)**

    ---

    4 hours. Make programs decide with `if`, and repeat work with `for` and `while`.

- **[Unit IV: Functions and Modules](unit-04-functions.md)**

    ---

    4 hours. Write reusable functions, use recursion, and import ready-made modules.

- **[Unit V: Data Structures in Python](unit-05-structures.md)**

    ---

    5 hours. Store data in lists, tuples, sets and dictionaries.

- **[Unit VI: File Handling and Exception](unit-06-files.md)**

    ---

    4 hours. Read and write files, work with CSV and JSON, and handle errors safely.

- **[Unit VII: Data Collection and Cleaning with Python](unit-07-cleaning.md)**

    ---

    4 hours. Load data with Pandas, fix missing values, duplicates and outliers, and reshape columns.

- **[Unit VIII: Exploratory Data Analysis](unit-08-eda.md)**

    ---

    5 hours. Summarize data with statistics, draw charts, and study correlation.

- **[Unit IX: Introduction to Machine Learning with Python](unit-09-ml.md)**

    ---

    6 hours. Supervised and unsupervised learning, regression, classification and clustering with Scikit-learn.

- **[Unit X: Data Visualization and Reporting](unit-10-visualization.md)**

    ---

    4 hours. Heatmaps, pair plots, interactive plots, and dashboards with Plotly Dash.

- **[Unit XI: Practical Lab Work](unit-11-lab.md)**

    ---

    6 hours. Hands-on projects that bring all the units together.
