# References

## Prescribed Textbooks

The syllabus prescribes two textbooks. Both teach Python itself very well.

1. **Matthes, Eric.** *Python Crash Course*. No Starch Press. Third edition, published December 2022. A hands-on book. It starts with the basics and finishes with projects. [Publisher page](https://nostarch.com/python-crash-course-3rd-edition).
2. **Lutz, Mark.** *Learning Python*. O'Reilly Media. Fifth edition, 2013. A long and careful reference. Read it when you want to know exactly how something works. [Publisher page](https://www.oreilly.com/library/view/learning-python-5th/9781449355722/).

!!! note "What the Textbooks Do Not Cover"

    Neither book teaches Pandas, scikit-learn or Dash. Units VII to X use the official documentation listed below. *Python Crash Course* does use Matplotlib and Plotly in its data chapters.

## Where Each Unit Is Covered

Chapter titles are from the publishers' tables of contents. Use them as a reading guide, not as a full match for the syllabus.

| Unit | Python Crash Course (third edition) | Learning Python (fifth edition) |

| III: Control structures | Chapter 5 if Statements; Chapter 7 User Input and while Loops | Part III Statements and Syntax: Chapter 12 if Tests and Syntax Rules; Chapter 13 while and for Loops |
| IV: Functions and modules | Chapter 8 Functions | The parts on functions and on modules |
| V: Data structures | Chapter 3 Introducing Lists; Chapter 4 Working with Lists; Chapter 6 Dictionaries | Part II: Chapter 8 Lists and Dictionaries; Chapter 9 Tuples, Files, and Everything Else |
| VI: Files and exceptions | Chapter 10 Files and Exceptions | Chapter 9 (files); the part on exceptions |
| X: Visualization | Chapters 15 to 17: Generating Data, Downloading Data, Working with APIs | Not covered |
| VII, VIII, IX, X (dashboards) | Not covered | Not covered |
